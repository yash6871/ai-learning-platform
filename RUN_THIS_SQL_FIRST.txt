IMPORTANT — run this in Supabase's SQL Editor BEFORE deploying the backend.

create_tables.py only creates missing TABLES, not missing COLUMNS on tables
that already exist. Without running this, the backend will crash with a
"column does not exist" error the first time a mock interview score is
logged.

-- New: custom total marks for a mock interview result (was hardcoded to /100)
ALTER TABLE mock_interview_evaluation ADD COLUMN IF NOT EXISTS max_score FLOAT DEFAULT 100;

-- (Older migration, keep if not already applied — safe to re-run, IF NOT EXISTS)
ALTER TABLE assessments ADD COLUMN IF NOT EXISTS active_from TIMESTAMPTZ;
ALTER TABLE assessments ADD COLUMN IF NOT EXISTS active_until TIMESTAMPTZ;
